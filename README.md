## IBM ## 
This repository contains coursework and project materials related to IBM's Data Science Professional Certificate program. It includes a final assignment notebook and a PDF detailing a technology trends dashboard.

Contents
Final Assignment.ipynb: A Jupyter Notebook encompassing the final assignment of the IBM Data Science course, featuring data analysis and visualization tasks.

Info on Technology Trends Dashboard.pdf: A PDF document providing insights into current technology trends, possibly summarizing findings or methodologies from the dashboard project.
